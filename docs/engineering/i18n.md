# i18n (Operasyonel)

ADR-0010'un uygulama rehberi.

## 1. Frontend

- react-i18next; diller `tr` (varsayılan) ve `en`, ikisi de her sürümde tam.
- Dosya düzeni: `apps/web/src/i18n/{tr,en}/<namespace>.json`; namespace = modül (`stock`, `materials`, `import`, `cutplan`, `orders`, `machines`, `common`, `errors`, `glossary`).
- Anahtar adı: `namespace:section.element` (`cutplan:toolbar.optimize`). Enum etiketleri `glossary:` altında (`glossary:material_type.SHEET`).
- Sabit metin yasak: ESLint `i18next/no-literal-string` (JSX). CI'da eksik anahtar (`tr` var `en` yok) hata.
- Çoğul ve sayı: i18next plural kuralları; asla `count + " parça"` birleştirmesi.
- Biçimlendirme tek yerde (`apps/web/src/format/`): `formatLength(um, unit)`, `formatMoney(minor, currency, locale)`, `formatDate(utc, locale, tz)`. Bileşen ham µm/minor görmez.

## 2. Backend

- Hata cevabı:
```json
{"code": "PART_EXCEEDS_SHEET", "params": {"part_label": "Yan-1", "sheet_length_um": 2800000}, "field": "rows[3].length_um"}
```
- Katalog: `packages/geppetto-contracts/src/geppetto_contracts/error_codes.py` — tek enum; her kod için `params` şeması docstring'de. Kod öneki domain alanı: `PART_`, `STOCK_`, `IMPORT_`, `SOLVER_`, `AUTH_`, `TENANT_`, `MATERIAL_`, `MACHINE_`, `EXPORT_`.
- Metin döndüren `HTTPException(detail=str)` yasak (test ile taranır).
- Çeviriler frontend `errors` namespace'inde; backend çeviri dosyası taşımaz.

## 3. Kanonik depolama

| Veri | Depolama | Sunum |
|---|---|---|
| Uzunluk | µm bigint | mm (tr/en), inç (opsiyon) — `formatLength` |
| Para | minor bigint + ISO 4217 | locale biçimi |
| Oran | basis point int | % |
| Zaman | UTC timestamptz | tenant/kullanıcı saat dilimi |
| Enum | `SCREAMING_SNAKE` | `glossary:` çevirisi |

## 4. `CountryPort`

```
CountryPort
  code -> str                       # "TR"
  default_currency -> str           # "TRY"
  vat_rates -> list[int]            # bp
  standard_sheet_sizes -> list[{length_um, width_um}]
  number_format / date_format hints
  fiscal_provider -> FiscalPort | None     # Faz 3
```

TR implementasyonu Faz 0. Ülkeye özgü `if` çekirdekte yasak.

## 5. Tenant ve kullanıcı

`Tenant.locale`, `Tenant.country_code`, `Tenant.base_currency`; `User.locale` (nullable, override). API `Accept-Language` yalnızca giriş öncesi ekranlar için.
